# Super Calculator - Python Project

## Overview

Super Calculator is a menu-driven Python application developed as part of my B.Tech learning journey. It combines mathematical, statistical, and matrix operations into a single program.

The project uses Python, NumPy, and the Math library to perform advanced calculations efficiently.

## Features

### Mathematical Operations

* Addition
* Subtraction
* Multiplication
* Division
* Square Root
* Power
* Logarithm
* Exponential Functions

### Trigonometric Operations

* Sine
* Cosine
* Tangent
* Inverse Sine
* Inverse Cosine
* Inverse Tangent

### Matrix Operations

* Matrix Addition
* Matrix Subtraction
* Matrix Multiplication
* Matrix Power
* Matrix Inverse
* Matrix Determinant
* Matrix Rank
* Matrix Diagonalization

### Statistical Operations

* Mean
* Median
* Mode
* Standard Deviation
* Correlation
* Skewness
* Linear Regression

## Technologies Used

* Python
* NumPy
* Math Module
